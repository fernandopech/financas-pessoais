# Mapa das contas

> Modelo com contas fictícias. Para que serve cada conta e como ela entra no sistema.

| Conta / cartão | Papel | Como entra no sistema |
|---|---|---|
| **Conta salário** | Recebe o salário e repassa para a principal | notificação; extrato |
| **Conta principal** | Débito, Pix, investimentos | notificação; extrato |
| **Cartão 1** | Crédito (vence dia X) | notificação; fatura |
| **Benefício** | Vale flexível da empresa (alimentação, mobilidade…) | notificação (traz o saldo) |
